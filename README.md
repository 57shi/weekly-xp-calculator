# 周经验值加成 / 衰减机制 计算器

CS2/CS:GO 周常经验计算器，单文件网页，双击即可打开（无需联网、无依赖）。

## 功能

- **本局记录**：每打完一局输入休闲得分，按「分段（边际）」方式折算经验
  - 分档以**到手经验**计：前 4,500 三倍 ×4、4,500–7,500 一倍 ×2、之后无加成 ×1、超过 11,167 按 17.5% 计入
  - 跨档的局自动拆成两段各算各的
- **经验进度（两条）**：
  - 升级条：当前经验（起点 + 已加）到 5,000 弹「升级」
  - 过载条：只算加出来的经验，到 11,167 弹「已过载」
  - 底部按「每局基准分」（默认 113，可改）估算还要几局升级 / 几局过载
- **加成曲线**：原始经验 → 有效经验对照图
- **反算**：想到达目标经验需要打多少
- **多开副本**：左侧栏可添加多个副本，各自独立保存记录与经验；右键删副本、一键重置当前副本
- **参数全可改**：分界线、各段倍率、衰减比例、休闲折算率、每局基准分

## 使用

直接双击 `weekly-xp-calculator.html` 用浏览器打开即可。记录保存在浏览器本地（localStorage），刷新不丢。
