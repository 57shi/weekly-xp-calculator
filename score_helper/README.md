# CS2 周经验计算器 · 截图 + 提取文字

微信那样的截图，外加「提取文字」把框里的数字自动填进计算器。

## 用法

1. 双击项目根目录的 `CS2周经验计算器.exe`
2. 画面停住（游戏全屏不用切）→ 按热键 **O**（可改）
3. 屏幕冻结变暗 → **拖一个框**圈住区域（选区里亮、外面暗，跟微信一样，还显示宽×高）
4. 松手弹出工具栏，只有两个功能：
   - **提取文字** — 识别框里的数字 → 自动填进网页的「本局得分」→ **自动点「确定」**
   - **截图** — 存到旁边的 `截图\` 文件夹 + 复制到剪贴板
   - Esc / 取消 — 放弃
5. 双击选区 = 直接复制

## 说明

- 计算器本体全部功能照常（本局记录、经验进度、加成曲线、反算、多开副本、参数）
- 「识别后自动点确定」可以在网页的「截图识别」面板里取消
- 热键在网页「参数设置 → 截图快捷键」或小助手窗口里改，两边同步
- **用自己浏览器打开页面时**，如果连不上小助手（502 是浏览器代理拦了本地请求）：请改用 exe 窗口，或把 `127.0.0.1` 加进系统代理例外地址
- 截图存 `截图\截图_年月日_时分秒.png`
